# Auditoría de TI

Herramientas y materiales que combinan mi experiencia en auditoría de TI
con programación, para automatizar pruebas y documentar controles.

## Áreas
Controles generales de TI (ITGC) · Seguridad de la información (ISO 27001) ·
Análisis de datos para auditoría

## Contenido
- **pruebas-asientos-contables:** scripts que detectan duplicados, montos
  redondos y anomalías en asientos de ejemplo.
- **segregacion-funciones:** revisión de conflictos entre roles con una
  matriz ficticia.
- **checklists-itgc:** listas de verificación de controles elaboradas a
  partir de normas públicas (ISO 27001, COBIT).
- **notas-iso27001-cisa:** notas de estudio en mis propias palabras.

> Todo el contenido usa datos sintéticos o públicos. No incluye
> información de clientes ni material de ninguna organización.
